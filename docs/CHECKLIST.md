# 실제 사이트 점검표 (작가님이 직접 확인)

> 자동 테스트는 가짜 서버로 돌아서, 아래는 **진짜 사이트**에서만 확인할 수 있어요.
> 주소: https://khj94591375-create.github.io/my-universe/
> 문제가 보이면 **화면 캡처 + 브라우저 이름(크롬/사파리 등) + 몇 번 항목인지**를 알려 주세요.

## 0. 데이터베이스 준비 확인 (한 번만)
1. Supabase 대시보드(supabase.com) → 프로젝트 열기
2. 왼쪽 **Table Editor** → `item_aliases` 표 클릭
3. 칸 이름 중에 **`source`**가 있으면 OK
4. 없으면: 왼쪽 **SQL Editor** → **New query** → 저장소의 `supabase/migrations/0004_ai_ready.sql` 내용을 붙여 넣고 **Run**
5. 같은 방법으로 왼쪽 **Table Editor**에 `style_terms` 표가 있는지 확인 → 없으면 `supabase/migrations/0005_style_terms.sql`을 붙여 넣고 **Run**(맞춤법 검사의 작품 사전)

## 1. 컴퓨터(크롬 또는 엣지)
| # | 할 일 | 이렇게 되면 정상 |
|---|---|---|
| 1 | 사이트 열기 | 왼쪽에 로고·소개·버튼, 오른쪽에 책 그림 |
| 2 | 오른쪽 위 `어둡게 보기` → 새로고침 | 어두운 화면이 그대로 유지 |
| 3 | 글자 모양 확인 | 본문이 둥글고 깔끔한 고딕(Pretendard), 제목 "My Universe"는 명조 |
| 4 | `구글로 시작하기` → 구글 계정 고르기 | 작품 목록으로 돌아옴, 오른쪽 위에 내 이메일 |
| 5 | `새 작품 만들기` → 이름 넣고 만들기 | 목록에 작품이 생김 |
| 6 | 작품 → `원고 불러오기` → `연습용 예시 원고 받기` 파일을 끌어 놓기 | 1~6화로 나뉘어 표에 나옴 → `저장하고 정리하기` → 검토 화면 |
| 7 | `우주 지도` | 별(동그라미·마름모·반짝별)이 보이고 이름이 겹치지 않음 |
| 8 | 별 두 개 누르기 → 오른쪽 ② | 두 별의 설명과 관계 |
| 9 | 지도 빈 곳 누르기 | 처음 상태로, 아래 알림의 `되돌리기`로 복구 |
| 10 | 왼쪽 아래 `로그아웃` | 시작 화면으로 |

## 2. 휴대폰(아이폰 사파리, 가능하면 안드로이드 크롬도)

|---|---|---|
| 11 | 사이트 열기 | 소개 → 그림 → 카드가 세로로, 옆으로 밀리지 않음 |
