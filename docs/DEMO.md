# 시연 시나리오 (기말 발표용)

> 목표: "원고를 올리면 세계관이 정리되고, 막혔을 때 잊힌 복선에서 다음 회차를 시작한다"를 5분 안에 보여 준다.
> 기준 문서: `docs/BUILD_SPEC.md` 1.1 핵심 사용 흐름. 배포 주소: https://khj94591375-create.github.io/my-universe/

## 0. 미리 준비 (발표 전날)

| 할 일 | 방법 |
|---|---|
| Supabase 깨우기 | 무료 프로젝트는 7일 안 쓰면 멈춘다. 대시보드에서 프로젝트를 열고 **Resume**(보이면) |
| 시연용 계정으로 로그인 | Google Cloud Console → 대상 → 테스트 사용자에 시연 계정이 있는지 확인 |
| 시연용 작품 만들기 | 작품 목록 → 새 작품 만들기 "별의 도서관(시연)" |
| 설정집 미리 채우기 | 리안(별칭 견습생·사서님), 세린(수석 사서), 검은 망토의 노인(노인), 책갈피 등불(등불), 금서 구역, 반쪽짜리 은열쇠(은열쇠), 달빛 서고의 규칙, 사라진 13번째 서가(열세 번째 서가), 푸른 잉크의 편지(푸른 편지) |
| 원고 파일 | 원고 불러오기 → 파일 올리기 → "연습용 예시 원고 받기"로 1~6화 txt를 받아 둔다 |
| 채점용 정답 | AI 정확도 채점 → "예시 정답 받기"로 CSV를 받아 둔다 |
| (AI 키를 넣었다면) | 시연 작품에서 AI 정리를 한 번 미리 돌려 두면 기다리는 시간이 없다 |

## 1. 시작 화면 (20초)
1. 배포 주소를 연다. 서비스 소개 세 줄을 읽어 준다.
2. **예시 작품 둘러보기**를 누른다. 로그인하지 않아도 볼 수 있고, 위에 "예시 작품 · 읽기 전용" 띠가 있다.

## 2. 원고 올리기 → 자동 정리 (1분)
1. 시연 작품 → **원고 불러오기** → 받아 둔 txt 파일을 끌어 놓는다.
2. 한 파일이 1~6화로 나뉘어 표에 나타난다(회차 번호·제목 자동).
3. **저장하고 정리하기** → "3/6 · 3화 정리 중" 진행 막대.
4. 검토 화면: 회차마다 나온 인물·설정과 **원고 속 근거 문장**, 같은 장면에 함께 나온 항목.
   - 말할 것: "규칙으로 찾은 것은 바로 확정, AI가 찾은 것은 'AI 추정'으로 따로 표시해요. 작가는 틀린 것만 고쳐요."

## 3. 홈 → 막혔어요 (1분)
1. **내 우주 홈**: "다음은 7화 차례예요", 오래 잊힌 복선(사라진 13번째 서가 5화째 미등장), 복선 회수 현황.
2. **막혔어요! 하나 골라주세요** → 가장 오래 잊힌 항목의 가이드가 열린다.
3. 시작 문장 예시와 방향 3개(회수·반전·암시), 각 방향 아래 **근거 문장(몇 화)**.
   - AI 키가 있으면 **AI 가이드 받기**: 원고에 없는 근거는 자동으로 빠진다는 점을 보여 준다.

## 4. 우주 지도 → 다음 회차 설계 (1분)
1. **우주 지도**: 별 밝기 = 오래 잊힐수록 희미. 휠로 확대, 별 이름 찾기.
2. 별 두 개(예: 반쪽짜리 은열쇠, 금서 구역)를 눌러 오른쪽에 담는다.
3. 별 정보창 → **연결 추가** → 방향과 관계 이름을 넣으면 화살표와 이름이 그려진다.
4. (AI 키가 있으면) **다음 회차 설계하기** → 장면 3개와 장면별 근거. 본문 초안 스위치는 기본 꺼짐.
   - 말할 것: "AI는 제안하고, 쓰는 건 작가예요."

## 5. 설정집·삽화 (40초)
1. **설정집**: 항목 수정, 별칭, 이미지 시트(그림 복사 → 칸 누르고 Ctrl+V).
2. (AI 키가 있으면) **설정 충돌 검사**: 근거 문장 두 개로 모순을 보여 준다.
3. **삽화 스튜디오**: 등장인물을 고르면 설정집 외모가 요청 문장에 자동으로 들어간다("보낼 요청 문장 미리보기"). 저작권 안내 문구.

## 6. 숫자로 보여 주기 (40초)
1. 내 설정 → **AI 정확도 채점** → 시연 작품 + 예시 정답 CSV → 채점하기.
2. "작가가 적은 항목 9개 중 N개를 찾았어요", 종류별 표, 놓친 항목 목록.
   - 본인 소설로 채점한 결과가 있으면 그 숫자를 보여 준다(원고는 저장소에 올리지 않는다).

## 문제가 생기면
| 증상 | 대처 |
|---|---|
| "데이터베이스가 아직 준비되지 않았어요" | Supabase가 멈춤 → 대시보드에서 Resume, 1~2분 뒤 새로고침 |
| 로그인 후 "연결할 수 없음" | Authentication → URL Configuration의 Site URL·Redirect URLs 확인 |
| AI 버튼이 회색 | 키가 없거나 함수가 아직 배포 안 됨 → 기본 가이드·규칙 결과로 진행(기본 기능은 AI 없이 동작) |
| "오늘 AI 사용량을 다 썼어요" | 다음 날 오전 9시에 다시 채워진다. 시연 전에는 Edge Functions Secrets의 한도 값을 잠시 올려 둔다 |
