# 작가 테스트 안내서 (M7)

> 목표(BUILD_SPEC 13장 M7): 신인 작가 3명 이상이 직접 써 보고, **"막혔어요"를 누른 뒤 3번 이내 클릭으로 가이드·설계를 받는지** 확인한다.
> 진행자 1명이 옆에서(또는 화면 공유로) 지켜보며 기록한다. 한 사람당 40분 정도.

---

## 1. 준비 (진행자)
- [ ] 테스트할 작가의 구글 계정으로 로그인할 수 있는지 미리 확인
- [ ] 작가에게 **자기 원고 3~6화**(txt·docx·pdf)를 준비해 달라고 부탁. 없으면 사이트의 `연습용 예시 원고 받기` 사용
- [ ] Claude Console(platform.claude.com) → Billing에서 크레딧이 남아 있는지 확인(한 사람당 약 500~1,000원 어림)
- [ ] 아래 "참가자에게 읽어 줄 말"과 "기록표"를 인쇄하거나 열어 두기
- [ ] 녹화하려면 반드시 미리 동의 받기

## 2. 참가자에게 읽어 줄 말
> "오늘은 작가님을 시험하는 게 아니라 이 사이트를 시험하는 거예요. 막히거나 헷갈리면 그건 사이트 잘못이니 편하게 말씀해 주세요.
> 생각나는 걸 소리 내어 말하면서 써 주시면 큰 도움이 돼요. 제가 도와드리지 않고 지켜보기만 할 거예요. 정말 막히면 '도와주세요'라고 해 주세요.
> 원고를 AI 기능에 쓰면 원고 일부가 AI 회사(Anthropic) 서버로 전송돼요. 원하지 않으시면 AI 버튼은 누르지 않으셔도 돼요."

## 3. 과제 (순서대로, 진행자는 설명하지 않고 과제 문장만 읽기)
| # | 과제 | 성공 기준 |
|---|---|---|
| 1 | 새 작품을 만들고 원고 3화 이상을 올려 정리해 주세요. | 정리 결과 검토 화면까지 도착 |
| 2 | AI가 찾은 인물·복선 중 맞는 것 3개를 확정하고, 틀린 것 1개를 지워 주세요. | 확정·삭제 완료 |
| 3 | 우주 지도에서 주인공과 가장 많이 이어진 별을 찾아 주세요. | 해당 별을 골라 관계 확인 |
| 4 | **(핵심)** 다음 회차가 막혔다고 생각하고, 사이트에 도움을 받아 보세요. | "막혔어요" 버튼을 누른 뒤 **3번 이내 클릭**으로 가이드나 설계를 받음 |
| 5 | "막힌 장면 풀기"에 지금 고민되는 장면을 적고 대안을 받아 보세요. | 대안 3개 확인 |
| 6 | 설정집에서 궁금한 것을 하나 물어보세요(예: "○○이 처음 나온 회차는?"). | 답과 근거 문장 확인 |
| 7 | 한 회차를 맞춤법 검사하고, 제안 하나는 적용·하나는 원문 유지해 보세요. | 고른 것만 교정본에 들어감 |
| 8 | 회차 기록 아래 "문체 분석"을 보고, 맞다고 느끼는지 말해 주세요. | 의견 기록 |

## 4. 마지막 질문 (5분)
1. 가장 쓸모 있었던 기능 하나와 그 이유는?
2. 가장 헷갈렸던 화면 하나는?
3. AI 결과 중 틀렸거나 엉뚱했던 것이 있었나요? (화면 캡처 부탁)
4. 원고가 AI 서버로 전송되는 것에 대해 어떻게 느끼셨나요?
5. 돈을 낸다면 한 달에 얼마까지 낼 수 있을까요? (안 낸다도 괜찮음)
