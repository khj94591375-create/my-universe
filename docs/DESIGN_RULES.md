# 디자인 규칙 (화면을 고칠 때 먼저 읽기)

이 앱의 화면 규칙이다. 색·글꼴·간격 값은 `src/styles/tokens.css`에만 둔다(CLAUDE.md 3번).
아래 규칙은 공개된 디자인 가이드 5개를 읽고, **우리 앱과 맞는 것만 골라 손으로 옮긴 것**이다.
가이드의 스크립트·설치 도구·훅은 쓰지 않는다(2026-11-28 결정).

## 1. 움직임
- 나타나고 사라지는 건 `var(--ease-out)`, 화면 안에서 옮겨 가는 건 `var(--ease-in-out)`, 서랍·시트는 `var(--ease-drawer)`. **ease-in은 쓰지 않는다**(시작이 굼떠 보인다).
- 시간: 버튼 누름 `--dur-press`(160ms), 작은 팝오버 `--dur-pop`(180ms), 대화상자 `--dur-panel`(280ms). 300ms를 넘기지 않는다.
- `transition: all` 금지. 바뀌는 속성만 적는다(transform, opacity, 색).
- 누를 수 있는 것은 눌렀을 때 반응한다: 버튼 `:active`에서 `scale(0.97)`.
- 올렸을 때(hover) 크기·위치가 바뀌는 효과는 `@media (hover: hover) and (pointer: fine)` 안에만 둔다(터치 기기에서 눌린 채 남지 않게).
- 움직임 줄이기 설정(prefers-reduced-motion)이면 위치·크기 움직임과 반복 애니메이션은 끄고 색·투명도 변화만 남긴다(`base.css`).
- 자주 쓰는 동작(타자, 목록 넘기기)에는 애니메이션을 넣지 않는다.

## 2. 접근성·조작
- 초점 표시는 `:focus-visible`만(마우스 클릭엔 안 보이고 키보드엔 보인다). 없애지 않는다.
- 아이콘만 있는 버튼은 `aria-label`. 클릭 동작은 `<button>`, 이동은 `<a>`/`Link`.
- 누르는 칸은 최소 44px(휴대폰).
- 숫자가 바뀌며 나란히 놓이는 곳(진행률·날짜·개수)은 `font-variant-numeric: tabular-nums`.
- 위에 붙은 상단바 때문에 가려지지 않게 `scroll-padding-top`(base.css).
- 휴대폰 높이는 `100vh` 대신 `100dvh`(주소창이 접혔다 펴져도 맞게).
- 옆으로 넘치는 스크롤은 `overflow-x: clip`으로 막는다(hidden은 붙는 상단바를 깨뜨린다).
- 다크 모드: `color-scheme`을 맞추고, 고르기 상자(select)는 바탕·글자색을 직접 준다. 휴대폰 주소창 색(`theme-color`)도 화면 바탕과 맞춘다.

## 3. "AI가 만든 티" 줄이기 (우리 앱 기준)
- 화면마다 **한 가지 주인공**만: 금색 강조(`--c-accent`)는 화면당 가장 중요한 버튼 하나.
- 상자 안에 상자를 겹치지 않는다. 구분은 여백과 얇은 선(1px `--c-line`)으로.
- 모서리 둥글기는 안쪽이 바깥보다 작게(안쪽 = 바깥 − 여백).
- 간격은 `--sp-*` 단계만 쓴다(임의의 13px, 22px 등 피하기).
- 무지개 그라데이션, 의미 없는 이모지 장식, 모든 카드에 같은 그림자를 넣지 않는다.
- 문구는 짧게. 같은 말을 제목·설명·버튼에서 반복하지 않는다(`copy.ts`).
- **예외**: 우주 지도의 성운 배경·별빛·금색 궤도는 작가님이 고른 시안이라 유지한다(가이드의 "빛나는 효과 금지"보다 작가님 시안이 우선).

## 4. 가져오지 않은 것과 이유
- 영어 전용 규칙(제목 첫 글자 대문자, 둥근 따옴표, 말줄임표 문자): 한국어 화면이라 해당 없음.
- 랜딩 페이지 전용 규칙(히어로 문구 공식, 사진 자동 내려받기): 우리는 작업 도구라 해당 없음.
- 가이드가 제공하는 검색·스냅샷 스크립트, 설정을 바꾸는 설치 도구·훅: 저장소와 개발 환경을 바꾸므로 쓰지 않는다.
